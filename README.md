# supreme-witness

Dated, public witness records for checks in SUPREME's plan.

- One issue per dated check, opened when the check is scheduled. Its milestone carries the due date.
- The result is posted on the issue as a dated comment on the due date, and the issue is then closed.
- A record with no result on its due date counts as no record, and a tripwire check with no record is deemed to have fired.
- Records carry a check ID, dates and a result, never client detail.
